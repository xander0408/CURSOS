# Cómo llevar la clase

Proyecte **`AI-Business-Lab-Como-llevar-la-clase.pptx`** (21 diapositivas). No recorra el temario de 94.

## Dinámica (siempre igual)

1. Dos minutos de idea.
2. Ellos hacen la tarea (laboratorio y/o ChatGPT y/o Claude).
3. Usted recorre el aula.
4. Cierre corto (mano arriba, 20–30 s).

Tres pestañas: laboratorio → ChatGPT → Claude. Si Claude se agota, el mismo texto en ChatGPT.
