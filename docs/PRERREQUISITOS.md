# Prerrequisitos — AI Business Lab (CISA)

Curso de 16 horas (2 viernes) para gerencias de **Central de Ingenios, S.A. de C.V.**  
Web corporativa: [http://www.cisahn.com/](http://www.cisahn.com/)

## Lo que debe tener cada alumno (antes del viernes 1)

### Cuentas (gratuitas)

1. Correo que recuerde (el institucional `@cisahn.com` sirve).
2. Cuenta en **ChatGPT** Free: [https://chatgpt.com/](https://chatgpt.com/)
3. Cuenta en **Claude** Free: [https://claude.ai/](https://claude.ai/)
4. Haber iniciado sesión una vez en cada una (para pasar el correo de verificación).

Detalle de límites Free: en el laboratorio, menú **Cuentas gratis**, o `docs/CUENTAS-GRATIS.md`.

### Equipo

- Computadora (Windows, Mac o Linux) con Chrome, Edge o Firefox actualizado.
- Internet estable. El laboratorio **no funciona bien** abriendo `index.html` a doble clic: se usa el enlace del instructor o `node serve.js`.
- **No** usar modo incógnito: el avance se guarda en el navegador, por usuario.
- Word, Excel y PowerPoint (o Google Docs/Sheets/Slides) para practicar fuera del chat.
- Audífonos opcionales si el aula es ruidosa.

### Conocimientos

- Nivel usuario: copiar, pegar, guardar un archivo, usar el correo.
- **No** se pide programación ni experiencia previa en IA.

### Actitud y seguridad

- Traer **una tarea real** de su cargo que le quite tiempo (sin datos confidenciales).
- Compromiso de **no pegar** nómina, contratos, claves, clientes identificables ni cifras oficiales no públicas.

### Acceso al laboratorio

- Usuario y contraseña individuales (los entrega el instructor; ver `CREDENCIALES-INSTRUCTOR.md`).
- Enlace del sitio (GitHub Pages o red local).

## Lo que debe tener el instructor (Magnatic)

### Antes del curso

- Lista de aula actualizada en `content/students.json`.
- Credenciales impresas o enviadas en privado.
- Proyector + la PPT `AI-Business-Lab-Presentacion.pptx` (F5, transiciones fade, diapositivas «Tu turno»).
- Enlace del laboratorio probado en el mismo tipo de red que el aula.
- PIN de notas: `CISA-Admin26`. Usuario admin: `instructor` / `MagnaTic#CISA26`.
- Guía `GUIA-INSTRUCTOR.md` y este documento.
- Plan B: si Claude se queda sin créditos, el grupo sigue en ChatGPT Free.

### En el aula

- Ronda **Conocernos** (5–8 min): nombre, cargo, una tarea que quita tiempo.
- Mostrar la **ruta** del portal: perfil → cuentas gratis → historia de la IA → módulos en orden.
- Asignación de tareas: ya viene por cargo; el instructor solo conecta la ronda con esa práctica.
- Recorrer el aula: cada quien muestra pantalla o exporta avance al final.

### Material de estudio que se desarrolla en el curso

- **Manual de prompts** (menú del laboratorio y plantillas de 5 piezas).
- Biblioteca personal en Prompt Lab (el alumno se lleva sus prompts).
- Tarea de cargo (anónima) + ficha del proyecto final.

## Qué NO es prerrequisito

- ChatGPT Plus, Claude Pro, ni API de pago.
- Instalar Python o VS Code (salvo el instructor si sirve el lab en local).
- Un servidor central con las notas de todos los alumnos.
