# Manual de prompts — material de estudio

Este manual se trabaja **dentro del laboratorio** (menú **Manual prompts** y **Prompt Lab**). No es para memorizar frases mágicas.

## Las 5 piezas (cópialas en cada encargo)

1. **Rol** — quién debe ser la IA.
2. **Contexto** — la situación, sin datos sensibles de CISA.
3. **Objetivo** — qué debe lograr.
4. **Formato** — correo, tabla, viñetas, 1 página…
5. **Restricciones** — qué no debe inventar; pedir el dato si falta.

## Ruta de los 2 viernes

- **Viernes 1:** 3 versiones del mismo encargo (pobre / mejor / con verificación). Guardar 2 prompts en la biblioteca.
- **Viernes 2:** un prompt de Excel con chequeo humano, uno de diapositiva con `[CIFRA OFICIAL]`, y el prompt maestro del proyecto de tu cargo.

Plantillas listas: laboratorio → Manual prompts. Tarea por cargo: pantalla Conocernos.
